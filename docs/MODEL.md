# Семантическая модель

## Ведун
`ВИДЕТЬ → РАСПОЗНАТЬ → ЗНАТЬ`

## Волхв
`СЛОВО → СМЫСЛ → РИТУАЛ`

## Вещун
`ЗНАНИЕ → ПЕРЕДАЧА → ВОЗВЕЩЕНИЕ`

## Знахарь
`ЗНАНИЕ → СРЕДСТВО → ПРИМЕНЕНИЕ`

## Характерник
`ХАРАКТЕР → ВОЛЯ → ДЕЙСТВИЕ`

## Общая петля
`ПАМЯТЬ → РАСПОЗНАВАНИЕ → ИНТЕРПРЕТАЦИЯ → КОММУНИКАЦИЯ → НАМЕРЕНИЕ → ДЕЙСТВИЕ → РЕФЛЕКСИЯ → ПАМЯТЬ`
