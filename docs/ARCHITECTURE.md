# Архитектура

```text
                  ┌───────────────┐
                  │     ВЕДУН     │
                  │ Knowledge     │
                  │ Memory        │
                  └───────┬───────┘
                          ↓
                  ┌───────────────┐
                  │     ВОЛХВ     │
                  │ Interpretation│
                  │ Symbolism     │
                  └───────┬───────┘
                          ↓
                  ┌───────────────┐
                  │    ВЕЩУН      │
                  │ Communication │
                  │ Proclamation  │
                  └───────┬───────┘
                          ↓
                  ┌───────────────┐
                  │     ВОЛЯ      │
                  │ Intention     │
                  └───────┬───────┘
                          ↓
                  ┌───────────────┐
                  │ ХАРАКТЕРНИК   │
                  │ Agency/Action │
                  └───────┬───────┘
                          ↓
                    Feedback → Memory
```

`Знахарь` выделен как прикладной семантический слой: знание → умение применять знание.

Проект намеренно не кодирует фольклорные сверхъестественные способности как
фактические физические возможности. Они представлены как элементы семантики,
нарратива и культурной модели.
